# React Portfolio Backend API

This is the backend service for my React portfolio and practice project. It serves as a headless API layer that connects to **Strapi** (headless CMS) and uses **Neon** as the database provider. The API is live and hosted on **Render.com**.

---

## 🛠️ Tech Stack

- **Strapi** – Headless CMS for content management
- **Neon** – Serverless PostgreSQL database
- **Render** – Cloud hosting and deployment
- **Node.js** – Runtime environment

---

## 📦 Features

- RESTful API endpoints generated by Strapi
- Content management via Strapi Admin Panel
- Database hosted on Neon (PostgreSQL)
- Environment variable configuration for security
- CORS enabled for frontend integration
- Ready for production deployment

---

## 🗄️ Database

This project uses **Neon** as the PostgreSQL database provider. Neon offers serverless, scalable, and always-on Postgres databases with branchable workflows.

- Database URL is configured via environment variables
- Strapi connects to Neon using the `DATABASE_URL` variable

---

## 🌐 Hosting

The backend is deployed on **Render.com** as a web service. Render automatically builds and deploys the project from the GitHub repository.

---

## 🔧 Environment Variables

Create a `.env` file in the root directory with the following variables:

```env
HOST=0.0.0.0
PORT=1337
APP_KEYS=your-app-keys
API_TOKEN_SALT=your-token-salt
ADMIN_JWT_SECRET=your-admin-jwt-secret
JWT_SECRET=your-jwt-secret
DATABASE_URL=your-neon-postgresql-url
